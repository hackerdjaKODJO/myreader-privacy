Delete your MyReader data

MyReader has no accounts and no developer server. You can delete reading data directly on your device. This page explains exactly what is deleted, what is kept, and how to ask for deletion of a public AI report.

App: MyReader (package com.myreader.reader)
Developer: MyReader project (individual developer)
Last updated: 14 November 2026

Delete on this device Email a deletion request

Fastest method: open Android Settings → Apps → MyReader → Storage & cache → Clear storage, or uninstall MyReader. This immediately deletes the app’s private data on that device. You do not need to create an account or email the developer.

1. Delete all MyReader data on your device

  1. Open Android Settings.
  2. Open Apps (or Apps & notifications) and choose MyReader.
  3. Open Storage & cache.
  4. Tap Clear storage (some devices call this Clear data).

Alternatively, uninstall MyReader. Uninstalling removes the app’s private data. If you want to keep the app, clearing storage is enough.

What “Clear storage” deletes

  • The recent-document list and last reading positions
  • Bookmarks, highlights and reading preferences
  • Saved AI notes, generated AI artifacts and Reading AI chat memory
  • The on-device Reading AI search index (book chunks and vectors)
  • Generated “book view” files and private cache files
  • Downloaded voice, translation and Reading AI model packs
  • WebView storage created by the in-app Google Translate view
  • Development/QA diagnostics logs, if a development build created any

Original documents are not deleted. MyReader opens your PDF, Office, EPUB, comic and text files through Android’s file picker and does not own or modify the originals. To delete an original file, delete it in the app or file manager where it is stored.

2. Delete only Reading AI data

If you want to keep your library, bookmarks and highlights but remove the local AI index and AI-generated data, use the in-app deletion action:

  1. Open MyReader.
  2. Open Reading AI.
  3. Open the Sources tab and find the AI data card.
  4. Tap Delete AI data and confirm.

This deletes the on-device search index, saved AI notes, generated AI artifacts, the AI cache and local chat memory. It does not delete bookmarks, highlights, original documents or installed model packs. To remove a model pack, use its delete action in Voice settings or Reading AI, or clear all app storage.

3. Delete a public AI answer report

If you used the in-app report/flag action, the report was posted as a public GitHub issue only after you confirmed and submitted it.

  • Open the GitHub issue you created and edit or delete it while signed in to the same GitHub account.
  • If you cannot edit it, open a request in the issue tracker or email the support address below with the issue URL. Do not include document contents or other sensitive information.
  • GitHub may retain issue history under its own policies even after an edit or deletion.

Issue tracker: github.com/hackerdjaKODJO/myreader-privacy/issues

4. Request deletion by email

You can also email jjwwww76@gmail.com with the subject “MyReader data deletion request”.

  • MyReader has no account or developer-held user database, so there is usually no server-side reading record to delete.
  • If your request concerns a public AI report, include its GitHub issue URL.
  • Do not send documents, passwords, identity documents or other sensitive data.
  • We aim to respond within 30 days. We may ask for enough information to locate a public report, but we will not ask for your document contents.

6. Data sent to optional third-party features

MyReader does not sell data and has no advertising, analytics or crash-reporting SDK. The following transfers happen only when you choose the relevant feature:

  • Google Translate: selected text and language parameters, when you tap Translate and on-device translation is unavailable or not installed.
  • Web references: your question and, for book-scoped questions, the book title, when you turn web references on. Book text, indexed passages and notes are not sent.
  • Public AI report: a question/answer excerpt, optional comment, app version and Android version, when you submit the prefilled public GitHub issue.
  • Model downloads: a request for the model file and standard HTTPS metadata. No document or user content is sent.

The full privacy policy explains these features, their recipients and their retention rules: MyReader Privacy Policy.
